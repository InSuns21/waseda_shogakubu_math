## このサイトについて

解答・解説の本文はリポジトリ内の `ans/*.md`、問題文は `probrems/*.md` をそのまま使用しています。Web 用に本文を複製していないため、Markdown を更新すると次回の GitHub Pages デプロイにそのまま反映されます。

数式は KaTeX で表示します。また、Markdown の更新時には GitHub Actions で KaTeX の構文検証を実行します。

## 注意

問題文には OCR に由来する誤りが含まれる可能性があります。明らかな OCR 誤りを補正して解いている場合は、各年の解答・解説内に注記しています。
